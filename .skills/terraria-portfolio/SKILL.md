# Terraria Portfolio

- Terraria es la principal referencia visual y de experiencia del proyecto.
- El objetivo es crear un portfolio que se sienta como explorar un mundo 2D estilo Terraria.
- No reducir la idea a simplemente poner una estética pixel-art sobre una web tradicional.
- El mundo debe sentirse vivo mediante capas, movimiento y ambientación.
- La claridad del portfolio sigue siendo importante.
- HTML debe contener el contenido real del portfolio.
- PixiJS puede encargarse del mundo visual y sus animaciones.
- Mantener pixel-art crisp.
- Usar sistemas reutilizables para sprites, partículas, parallax y animaciones.
- Evitar dependencias innecesarias.
- Priorizar performance.
- Desktop y mobile pueden tener composiciones diferentes.
- Respetar `prefers-reduced-motion`.
- No implementar decisiones visuales importantes que todavía no hayamos discutido.
- No completar documentos de diseño inventando decisiones.
- Registrar únicamente decisiones tomadas durante nuestras conversaciones.

Antes de implementar una feature importante, revisar las referencias relacionadas: `references/DESIGN-BRIEF.md`, `references/world-design.md`, `references/asset-map.md`, `references/animation-guidelines.md` y `references/architecture.md`.
