# Fuente y criterio editorial

La fuente de los textos, enlaces, formación, skills, servicios y galerías es el portfolio publicado en [martohg.github.io](https://martohg.github.io/), consultado durante la implementación. Se preservaron las tres fichas de proyecto, el contenido de “De Senda a una skill” y los textos alternativos publicados para las capturas. Las URLs de las 25 capturas respondieron correctamente al verificarlas.

Los campos `summary` son resúmenes editoriales para las tarjetas y el encabezado de cada caso; condensan el contenido de `problem`, `solution` y `role`, no son citas textuales del sitio. Los títulos de galería y nombres de zona describen la organización espacial de este portfolio. No se agregaron métricas, clientes, repositorios ni resultados que no aparezcan en la fuente.

`PROJECTS` contiene los tres casos convencionales. `SKILL_PROJECT` mantiene “De Senda a una skill” como ficha editorial propia, sin capturas, y `getProject` resuelve los cuatro edificios de contenido.
